# 自动化打谱服务平台 — 需求分析文档

## 1. 项目概述

### 1.1 产品定位
一个**自动化乐谱转录与销售平台**，对外通过**淘宝店铺**和**自建乐谱网站**两个渠道提供服务。系统维护一个乐谱数据库，对已有乐谱实现自动售卖、自动发货；对库中没有的乐谱，通过 AI 自动打谱 + 管理员审核的方式在一天内完成交付。

### 1.2 核心业务模式
```
用户需要某首乐谱
        │
        ├── 数据库中已有 → 自动售出、自动发货（秒级）
        │
        └── 数据库中没有
                │
                ├── 用户有图片版 → 用户上传 → AI 自动打谱 → 管理员审核 → 交付（≤1天）
                │
                └── 用户没有图片版 → 系统从网上抓取 → 打水印 → 与用户确认
                        │                                       是否是该乐谱
                        └── 确认后 → AI 自动打谱 → 管理员审核 → 交付（≤1天）
```

### 1.3 对外渠道
| 渠道 | 定位 | 核心功能 |
|------|------|---------|
| **淘宝店铺** | 销售渠道 | 自动上架、自动发货、客服消息对接 |
| **乐谱网（自建网站）** | 品牌渠道 + 搜索入口 | 乐谱搜索、在线浏览、上传定制、注册、订单管理 |

### 1.4 目标用户
| 用户群体 | 典型场景 |
|---------|---------|
| 琴行老师 | 需要教学用谱，淘宝下单即得 |
| 音乐学生 | 搜索某首曲子的谱，找不到就定制 |
| 合唱团/乐队 | 批量需要某些曲目的规范乐谱 |
| 教堂/宗教团体 | 赞美诗等历史乐谱数字化 |
| 独立音乐人 | 将自己的手稿转为专业乐谱 |

### 1.5 核心价值主张
- **快**：已有谱秒发，定制谱一天内交付
- **省**：相比人工打谱（每页 50-200 元），价格大幅降低
- **专业**：基于 LilyPond 的出版级排版质量
- **方便**：淘宝下单或网站搜索，无需学习打谱软件

## 2. 功能需求

### 2.1 渠道层 — 淘宝店铺对接

#### F1: 淘宝店铺自动化
- **自动上架**：乐谱数据库中的谱自动同步到淘宝商品
  - 每首乐谱生成一个淘宝商品（标题、封面、描述、标签）
  - 新入库的乐谱自动创建商品
- **自动发货**：
  - 客户下单后，系统自动发送乐谱文件（PDF）到买家
  - 通过淘宝开放平台 API 实现自动发货
  - 发货方式：站内消息发送下载链接 / 虚拟商品自动发货
- **库中无货处理流程**：
  1. 买家咨询某首乐谱，系统自动查询数据库
  2. 若有 → 引导购买，下单后自动发货
  3. 若无 → 自动回复："暂无此谱，是否有图片版？"
  4. 买家提供图片 → 告知"需要1天时间打谱"，创建打谱任务
  5. 买家无图片 → 系统从网上搜索该乐谱图片 → 打水印 → 发给买家确认 → 确认后创建打谱任务
- **淘宝 API 集成**：
  - 使用淘宝开放平台（TOP）SDK
  - 商品管理 API（创建/修改/下架）
  - 订单管理 API（查询/发货）
  - 消息 API（客服消息收发）
  - Webhook 接收订单通知

#### F2: 淘宝客服自动应答
- 基于关键词 + AI 的智能客服
- 自动识别买家意图（查谱、问价、催单等）
- 预设话术模板 + 动态信息填充
- 无法处理的消息转发给管理员

### 2.2 渠道层 — 乐谱网（自建网站）

#### F3: 乐谱搜索与浏览
- **搜索功能**：
  - 按曲名、作曲家、乐器、调号、难度等搜索
  - 模糊搜索 + 拼音/英文支持
  - 搜索结果展示：封面缩略图、曲名、作曲家、页数、价格
- **分类浏览**：
  - 按乐器分类（钢琴、吉他、小提琴、声乐等）
  - 按风格分类（古典、流行、爵士、宗教等）
  - 按难度分级
  - 热门/最新排行
- **乐谱详情页**：
  - 乐谱封面 / 第一页预览（带水印）
  - 基本信息（调号、拍号、页数、难度）
  - 价格 + 购买按钮
  - MIDI 试听（V2）

#### F4: 搜索不到时的定制流程
- 用户搜索无结果时，页面显示"找不到？帮你找！"入口
- **流程**：
  1. 用户输入曲名或描述
  2. 可选：上传已有的图片版乐谱
  3. 若用户未上传图片：
     - 系统自动从网络抓取可能匹配的乐谱图片
     - 图片打上本站水印
     - 展示给用户确认："是这首吗？"
  4. 用户确认后，系统显示报价和预计交付时间（1天内）
  5. 用户支付定金/全款
  6. 系统创建打谱任务，进入 AI 打谱 → 管理员审核流程
  7. 完成后通知用户下载

#### F5: 用户系统
- **注册/登录**：
  - 手机号 + 验证码
  - 微信扫码登录
  - 邮箱 + 密码
- **个人中心**：
  - 已购乐谱（可重复下载）
  - 定制订单状态跟踪
  - 消费记录
  - 个人信息管理

#### F6: 订单管理（用户端）
- 订单列表：全部 / 待支付 / 制作中 / 已完成 / 已退款
- 订单详情：
  - 乐谱信息
  - 支付状态
  - 制作进度（待打谱 → 打谱中 → 审核中 → 已完成）
  - 下载入口（完成后）
  - 退款申请入口

### 2.3 核心引擎层 — 乐谱数据库

#### F7: 乐谱库管理
- **乐谱入库**：
  - 管理员手动添加
  - AI 打谱审核通过后自动入库
  - 批量导入（CSV + 文件包）
- **乐谱元数据**：
  - 曲名（中/英）、作曲家、编曲者
  - 乐器类型、调号、拍号
  - 难度等级、风格分类、标签
  - 页数、时长估算
- **乐谱文件**：
  - LilyPond 源文件（.ly）
  - PDF 输出（无水印 + 带水印版）
  - PNG 缩略图 / 预览图
  - MusicXML（通用交换格式）
  - MIDI 文件（V2）
- **库存状态**：有货 / 制作中 / 已下架

#### F8: 乐谱搜索引擎
- 全文检索（Elasticsearch / Meilisearch）
- 支持中文分词
- 同义词/别名映射（如"致爱丽丝" = "献给爱丽丝" = "Für Elise"）
- 搜索权重：曲名 > 作曲家 > 标签 > 描述

### 2.4 核心引擎层 — AI 自动打谱

#### F9: 图片预处理
- 支持格式：JPG, PNG, PDF（单页/多页）
- 自动裁剪、去噪、倾斜校正、对比度增强
- 灰度化、二值化
- 谱表检测与分割
- 单文件最大 20MB，单次最多 50 页

#### F10: 音乐光学识别（OMR）
- **技术方案**：专用 OMR 引擎（HOMR/SMT++/Legato）+ LLM 后处理
  - 主引擎：开源专用 OMR 模型进行符号识别
  - LLM 后处理：音乐理论校验、格式转换、模糊区域消歧
- **识别内容**：
  - 音符（音高、时值、附点、连音）
  - 休止符
  - 谱号（高音、低音、中音等）
  - 调号、拍号
  - 小节线、反复记号
  - 力度记号（p, f, mf, ff 等）
  - 连线（连音线、圆滑线）
  - 歌词文本
  - 和弦符号
- **处理流程**：
  ```
  原始图片
      │
      ▼
  [1] 图片预处理（去噪、校正、二值化）
      │
      ▼
  [2] 专用 OMR 引擎识别（HOMR/SMT++）
      │  输出: MusicXML / kern 格式
      ▼
  [3] LLM 后处理
      │  - 校验结构一致性（拍子对齐、调号正确）
      │  - 修正明显错误（不可能的节奏、和声冲突）
      │  - 合并逐小节输出为完整乐谱
      ▼
  [4] LilyPond 代码生成
      │  MusicXML → LilyPond 语法转换
      │  排版优化（分页、间距）
      ▼
  [5] LilyPond 渲染
      │  .ly → PDF / PNG / MIDI
      ▼
  [6] 生成审核任务 → 等待管理员确认
  ```

#### F11: LilyPond 排版输出
- 将识别结果转为 LilyPond 源码
- 调用 LilyPond 引擎渲染
- 输出格式：PDF（主要）、PNG、SVG
- 支持下载 LilyPond 源文件
- 支持导出 MusicXML

### 2.5 核心引擎层 — 管理员审核

#### F12: 任务管理系统
- **任务列表**：
  - 显示所有待审核的打谱任务
  - 任务信息：曲名、来源（淘宝/乐谱网）、客户、创建时间、优先级、状态
  - 状态：待处理 → 打谱中 → 待审核 → 审核通过 / 需返工
  - 按优先级、时间排序
  - 筛选：按状态、来源、日期
- **任务详情**：
  - 客户信息、需求描述
  - 原始图片
  - AI 打谱结果
  - 操作：进入审核编辑器 / 转给其他管理员

#### F13: 审核编辑器（核心交互界面）
- **布局**：
  ```
  ┌──────────────────────────────────────────────────┐
  │  工具栏：保存 | 撤销/重做 | 播放 | 审核完成       │
  ├────────────────────┬─────────────────────────────┤
  │                    │                             │
  │   左侧面板         │   右侧面板                   │
  │   原始图片          │   可编辑的乐谱               │
  │                    │                             │
  │   - 可缩放         │   - 基于 OSMD/VexFlow 渲染   │
  │   - 可平移         │   - 可拖拽音符改变音高        │
  │   - 标注高亮       │   - 点击添加/删除音符         │
  │                    │   - 修改时值（右键菜单）      │
  │                    │   - 添加/修改标记             │
  │   [同步滚动]       │   [实时预览]                  │
  │                    │                             │
  ├────────────────────┴─────────────────────────────┤
  │  底部：小节导航条 | 当前小节信息 | 置信度标识       │
  └──────────────────────────────────────────────────┘
  ```
- **编辑功能**：
  - 音符操作：
    - 拖拽上下移动改变音高
    - 点击选中后用键盘微调（上下箭头改音高，左右箭头选下一个）
    - 右键菜单修改时值（全音符/二分/四分/八分/十六分）
    - 添加/删除附点、升降号
    - 添加/删除连线
  - 小节操作：
    - 插入小节
    - 删除小节
    - 复制/粘贴小节
  - 标记操作：
    - 添加力度记号
    - 添加速度标记
    - 添加反复记号
    - 添加歌词文本
  - 辅助功能：
    - 低置信度区域自动高亮标红
    - 原图对应区域联动高亮
    - 撤销/重做（Ctrl+Z / Ctrl+Shift+Z）
    - 键盘快捷键
- **审核完成流程**：
  1. 管理员点击"审核完成"
  2. 系统生成最终 PDF（无水印）
  3. 乐谱自动入库
  4. 系统自动发送给对应客户（淘宝发货 / 网站通知 + 下载链接）
  5. 订单状态更新为"已完成"

### 2.6 网络乐谱抓取

#### F14: 乐谱图片抓取
- **触发条件**：用户需要某首谱，库中没有，用户也没有图片
- **抓取流程**：
  1. 根据曲名 + 作曲家等关键词搜索
  2. 抓取候选图片（来自公开乐谱网站）
  3. 自动打上本站水印（防止用户直接使用）
  4. 展示给用户确认
- **抓取来源**（示例）：
  - IMSLP（公共领域乐谱）
  - Musescore 社区分享
  - 其他公开乐谱资源
- **注意事项**：
  - 仅抓取公共领域 / 合法来源的乐谱
  - 水印需覆盖关键区域但不影响辨识
  - 抓取结果缓存，避免重复请求

### 2.7 扩展功能（V2+）

#### F15: MIDI 播放
- 将乐谱转为 MIDI，网页内嵌播放器试听

#### F16: 移调工具
- 一键移调功能

#### F17: 批量打谱
- 支持机构客户批量提交打谱需求

#### F18: API 开放
- 提供 REST API 供第三方集成
- 按调用次数计费

## 3. 非功能需求

### 3.1 性能
| 指标 | 目标值 |
|------|-------|
| 已有乐谱查询响应 | < 500ms |
| 自动发货延迟 | < 30 秒（从下单到发货） |
| 图片上传响应 | < 2 秒 |
| OMR 识别（单页） | < 60 秒 |
| LilyPond 渲染（单页） | < 10 秒 |
| 端到端自动打谱 | < 5 分钟（AI 部分，不含审核） |
| 网站页面加载 | < 3 秒 |
| 搜索响应 | < 1 秒 |
| 并发用户数 | 100+（初期） |

### 3.2 可用性
- 乐谱网：响应式设计，支持桌面和移动端
- 管理后台：桌面端优先（编辑器需要大屏）
- 核心流程简洁：搜索 → 购买 → 下载（3步）

### 3.3 安全性
- HTTPS 全站加密
- 用户数据加密存储
- 支付走第三方安全通道
- 上传文件类型校验 + 病毒扫描
- 防爬虫措施（乐谱文件保护）
- 下载链接有时效性（防盗链）

### 3.4 可扩展性
- 微服务架构，OMR 引擎和 LilyPond 渲染可独立扩缩容
- 任务队列异步处理
- CDN 加速静态资源和乐谱文件

### 3.5 可靠性
- 淘宝 API 对接需有重试机制（网络抖动）
- 打谱任务失败自动重试 + 告警
- 数据库定期备份
- 乐谱文件多地冗余存储

### 4.2 技术选型

| 层级 | 技术 | 理由 |
|------|------|------|
| **乐谱网前端** | Next.js + TypeScript | SSR/SEO 友好，利于搜索引擎收录 |
| **管理后台前端** | React + Ant Design | 成熟的后台 UI 框架 |
| **乐谱编辑器** | OpenSheetMusicDisplay (OSMD) + 自定义交互层 | 成熟的 Web 乐谱渲染库 |
| **后端** | Python FastAPI | 高性能异步，ML 生态好 |
| **任务队列** | Celery + Redis | 异步处理打谱任务 |
| **搜索引擎** | Meilisearch | 轻量、中文友好、搜索体验好 |
| **OMR 引擎** | HOMR（初期）→ SMT++/Legato（升级） | 开源、免费、精度高 |
| **LLM 后处理** | Claude API | 音乐理论校验、格式转换 |
| **排版引擎** | LilyPond | 开源、出版级质量 |
| **淘宝对接** | 淘宝开放平台 TOP SDK (Python) | 官方 SDK |
| **网络抓取** | Playwright + BeautifulSoup | 动态页面 + 静态页面抓取 |
| **水印** | Pillow (PIL) | Python 图片处理 |
| **数据库** | PostgreSQL | 可靠、功能强大 |
| **缓存/队列** | Redis | 缓存 + Celery broker |
| **文件存储** | 阿里云 OSS | 成本低、国内访问快 |

## 6. 用户流程

### 6.1 淘宝买家流程
```
[买家] 在淘宝搜索乐谱
        │
        ├── 找到商品 → 下单付款 → 自动收到 PDF → 完成
        │
        └── 没找到 → 咨询客服
                │
                ├── 客服自动回复："请提供曲名"
                │   │
                │   ▼
                │  系统查库 → 有货 → 引导买家购买商品链接
                │           → 无货 → "有图片版吗？"
                │               │
                │               ├── 有 → 买家发图 → "需要1天，请下单XX元"
                │               │                    → 买家下单 → 打谱 → 审核 → 发货
                │               │
                │               └── 没有 → 系统搜图 → 发水印图 → "是这首吗？"
                │                         → 确认 → 同上流程
                │
                └── 复杂问题 → 转人工客服
```

### 6.2 乐谱网用户流程
```
[用户] 访问乐谱网
        │
        ├── 浏览分类 / 搜索曲名
        │       │
        │       ├── 找到 → 预览（水印版）→ 付款 → 下载 PDF
        │       │
        │       └── 没找到 → 点击"帮我找"
        │               │
        │               ├── 输入曲名 + 上传图片（可选）
        │               │
        │               ├── 无图片 → 系统搜图 → 展示水印候选 → 用户确认
        │               │
        │               └── 付款 → 提交定制 → 等待（≤1天）→ 收到通知 → 下载
        │
        └── 注册/登录 → 个人中心 → 查看订单、已购乐谱
```

### 6.3 管理员流程
```
[管理员] 打开后台
        │
        ├── 查看任务列表（待审核任务优先显示）
        │       │
        │       ▼
        │   点击某个任务
        │       │
        │       ▼
        │   审核编辑器打开
        │   左侧：原始图片（可缩放、标注）
        │   右侧：系统生成的可编辑乐谱
        │       │
        │       ├── 拖拽音符调整音高
        │       ├── 修改音符时值
        │       ├── 添加/删除音符、小节
        │       ├── 添加标记（力度、速度等）
        │       │
        │       ▼
        │   点击"审核完成"
        │       │
        │       ▼
        │   系统自动：
        │   1. 生成最终 PDF
        │   2. 乐谱入库
        │   3. 发送给客户
        │   4. 更新订单状态
        │
        ├── 乐谱库管理（增删改查、上下架）
        │
        └── 数据统计（订单量、收入、转化率）
```

## 8. 风险与应对

| 风险 | 影响 | 应对策略 |
|------|------|---------|
| OMR 识别准确率不够 | 管理员审核工作量大 | 1) 使用最佳开源 OMR 2) LLM 后处理提升 3) 初期限制复杂谱 |
| 淘宝 API 变动 | 自动化流程中断 | 1) 监控 API 状态 2) 预留人工操作备用流程 3) 关注淘宝开发者公告 |
| 抓取的图片版权问题 | 法律风险 | 1) 优先使用 IMSLP 等公共领域资源 2) 仅作确认用途，打水印 3) 最终交付的是自行排版的新谱 |
| 手写谱识别困难 | 定制失败率高 | 初期聚焦印刷谱，手写谱标注为 Beta |
| 一天交付承诺难兑现 | 客户投诉 | 1) AI 预处理减少人工量 2) 设置优先级队列 3) 高峰期调整承诺时间 |
| 竞品威胁 | 市场被抢 | 差异化：LilyPond 出版级质量 + 全自动化流程 |
| 支付合规 | 法律风险 | 使用正规第三方支付通道 |
