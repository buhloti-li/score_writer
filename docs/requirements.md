# 在线打谱软件 — 需求分析文档

## 1. 项目概述

### 1.1 产品定位
一个在线音乐打谱服务平台，用户上传手写或印刷乐谱的照片，系统通过 AI 识别 + LilyPond 排版引擎，输出专业、清晰的乐谱（PDF/PNG/MusicXML），并通过按次付费和会员订阅两种模式实现商业化。

### 1.2 目标用户
| 用户群体 | 需求场景 |
|---------|---------|
| 音乐教师 | 将手写教材转为专业乐谱分发给学生 |
| 作曲/编曲人 | 将草稿快速转为规范乐谱 |
| 合唱团/乐队 | 将老旧纸质谱整理为电子版 |
| 音乐学生 | 作业、练习曲的规范化 |
| 教堂/宗教团体 | 赞美诗等历史乐谱数字化 |

### 1.3 核心价值主张
- **省时**：手动打谱一首曲子可能需要数小时，本平台分钟级完成
- **专业**：基于 LilyPond 的出版级排版质量
- **便宜**：相比请人打谱（每页 50-200 元），价格大幅降低
- **方便**：拍照上传，无需学习任何打谱软件

## 2. 功能需求

### 2.1 核心功能（MVP）

#### F1: 乐谱图片上传
- 支持格式：JPG, PNG, PDF（单页/多页）
- 支持来源：手机拍照、扫描件、截图
- 图片预处理：自动裁剪、去噪、倾斜校正、对比度增强
- 限制：单文件最大 20MB，单次最多上传 50 页

#### F2: 音乐光学识别（OMR）
- 识别内容：
  - 音符（音高、时值、附点、连音）
  - 休止符
  - 谱号（高音、低音、中音等）
  - 调号、拍号
  - 小节线、反复记号
  - 力度记号（p, f, mf, ff 等）
  - 连线（连音线、圆滑线）
  - 歌词文本
  - 和弦符号
- 技术方案：AI/ML 模型（基于深度学习的 OMR）+ 后处理规则引擎

#### F3: 人工校对/编辑界面
- 识别结果的可视化预览
- 允许用户逐小节确认/修正识别结果
- 基础编辑功能：修改音符、添加/删除小节、调整标记
- 实时预览修改后的乐谱效果

#### F4: LilyPond 排版输出
- 将识别结果转为 LilyPond 源码
- 调用 LilyPond 引擎渲染
- 输出格式：PDF（首选）、PNG、SVG
- 支持下载 LilyPond 源文件（高级用户自行微调）
- 支持下载 MusicXML（通用交换格式）

#### F5: 用户系统
- 注册/登录（邮箱 + 密码、微信登录、Google 登录）
- 个人中心：历史订单、已生成乐谱管理
- 乐谱收藏夹

### 2.2 商业功能

#### F6: 按次付费
- 按"乐章/乐曲"计费（非按页）
- 定价策略：
  - 简单谱（单声部，1-2 页）：¥5-10 / 首
  - 中等谱（多声部/钢琴谱，3-5 页）：¥15-30 / 首
  - 复杂谱（管弦乐总谱，5+ 页）：¥50-100 / 首
- 预览水印版免费，下载无水印版付费
- 支付方式：微信支付、支付宝、Stripe（国际）

#### F7: 会员订阅
| 方案 | 月费 | 年费 | 权益 |
|------|------|------|------|
| 免费版 | ¥0 | ¥0 | 每月 2 首免费，带水印 |
| 基础版 | ¥29 | ¥299 | 每月 20 首，无水印，标准排版 |
| 专业版 | ¥79 | ¥799 | 无限量，无水印，高级排版选项，优先处理 |
| 团队版 | ¥199 | ¥1999 | 5 个账号，无限量，协作功能，API 接入 |

#### F8: 积分/优惠体系
- 新用户注册赠送 3 次免费转换
- 邀请好友各得 1 次免费
- 节假日/促销折扣

### 2.3 扩展功能（V2+）

#### F9: MIDI 播放
- 将识别结果转为 MIDI
- 网页内嵌播放器，试听乐谱

#### F10: 移调/编曲工具
- 一键移调
- 简单的声部拆分/合并

#### F11: 协作功能
- 多人共同编辑一份乐谱
- 评论/标注功能

#### F12: API 开放
- 提供 REST API 供第三方集成
- 按调用次数计费

## 3. 非功能需求

### 3.1 性能
| 指标 | 目标值 |
|------|-------|
| 图片上传响应 | < 2 秒 |
| OMR 识别（单页） | < 30 秒 |
| LilyPond 渲染（单页） | < 10 秒 |
| 端到端处理（简单谱） | < 2 分钟 |
| 页面加载时间 | < 3 秒 |
| 并发用户数 | 100+（初期） |

### 3.2 可用性
- 响应式设计，支持桌面和移动端
- 核心流程 3 步完成：上传 → 校对 → 下载
- 提供使用教程和示例

### 3.3 安全性
- HTTPS 全站加密
- 用户数据加密存储
- 支付走第三方安全通道（不存储敏感支付信息）
- 上传文件病毒扫描
- GDPR/个人信息保护合规

### 3.4 可扩展性
- 微服务架构，OMR 引擎和 LilyPond 渲染可独立扩缩容
- 任务队列异步处理，避免阻塞
- CDN 加速静态资源和生成的乐谱文件

### 4.2 技术选型

| 层级 | 技术 | 理由 |
|------|------|------|
| **前端** | Next.js (React) + TypeScript | SSR/SEO 友好，生态丰富 |
| **UI 组件** | Tailwind CSS + shadcn/ui | 快速开发，美观现代 |
| **乐谱编辑器** | OpenSheetMusicDisplay (OSMD) 或 VexFlow | 成熟的 Web 乐谱渲染库 |
| **后端** | Python FastAPI | 高性能异步，ML 生态好 |
| **任务队列** | Celery + Redis | 异步处理 OMR 和渲染任务 |
| **OMR 引擎** | Audiveris + 自训练模型 | Audiveris 开源成熟；自训练模型补充手写识别 |
| **AI 增强** | Claude API / GPT-4V | 辅助识别模糊/复杂记谱 |
| **排版引擎** | LilyPond | 开源，出版级质量，业界标准 |
| **数据库** | PostgreSQL | 可靠，功能强大 |
| **文件存储** | 阿里云 OSS / AWS S3 | 可扩展的对象存储 |
| **支付** | 微信支付 + 支付宝 + Stripe | 覆盖国内外用户 |
| **部署** | Docker + Kubernetes | 容器化，弹性伸缩 |
| **CI/CD** | GitHub Actions | 自动化测试和部署 |

### 4.3 OMR 识别流程

```
原始图片
    │
    ▼
[1] 图片预处理
    - 灰度化、二值化
    - 倾斜校正（Hough 变换）
    - 去噪（中值滤波）
    - 谱表检测与分割
    │
    ▼
[2] 符号检测
    - 基于 YOLO/Faster R-CNN 的目标检测
    - 检测音符头、符干、符尾、休止符、
      谱号、调号、拍号等
    │
    ▼
[3] 符号分类
    - CNN 分类器
    - 区分全音符/二分/四分/八分/十六分等
    │
    ▼
[4] 空间关系分析
    - 音符在谱表中的位置 → 音高
    - 符号的时序排列 → 节奏
    - 上下文语义分析（调号影响、连线范围等）
    │
    ▼
[5] 音乐语义重建
    - 组装为结构化的音乐数据（MusicXML 中间格式）
    - 规则引擎校验（拍子是否对齐、和声合理性等）
    │
    ▼
[6] LilyPond 代码生成
    - MusicXML → LilyPond 语法转换
    - 排版优化（分页、间距、字体）
```

## 6. 用户流程

### 6.1 核心流程（上传到下载）

```
[用户] 拍照/选择图片
        │
        ▼
[上传页] 拖拽或选择文件 → 自动预处理预览
        │
        ▼
[等待页] 显示处理进度（预处理 → 识别 → 排版）
        │  ← WebSocket 实时推送进度
        ▼
[校对页] 左侧: 原图 ↔ 右侧: 识别结果乐谱预览
        │  用户可修正错误
        ▼
[预览页] 完整乐谱预览（带水印）
        │
        ├── 免费用户 → 提示付费 → 支付 → 下载无水印版
        └── 会员用户 → 直接下载无水印版
```

### 6.2 新用户首次体验

```
落地页 → 免费试用（无需注册） → 上传一张图 → 看到效果
→ 注册获取结果 → 引导付费/订阅
```

## 7. 风险与应对

| 风险 | 影响 | 应对策略 |
|------|------|---------|
| OMR 识别准确率不够 | 用户体验差，口碑下降 | 1) 人工校对兜底 2) 持续优化模型 3) 初期限制复杂谱类型 |
| 手写谱识别困难 | 限制用户群 | 初期聚焦印刷谱，手写谱标注为 Beta |
| LilyPond 渲染慢 | 影响用户等待体验 | 1) 预编译缓存 2) 分布式渲染 3) 异步+进度提示 |
| 支付合规 | 法律风险 | 使用正规第三方支付，取得相关资质 |
| 版权争议 | 法律风险 | 用户协议声明版权责任归用户；不存储公开分享 |
| 竞品威胁 | 市场被抢 | 差异化：LilyPond 出版级质量 + 低价 |

## 9. 竞品分析

| 产品 | 特点 | 价格 | 我们的优势 |
|------|------|------|-----------|
| **ScanScore** | 桌面端 OMR，识别率较高 | €59-149 买断 | 我们是在线服务，无需安装 |
| **PlayScore** | 移动端 OMR + 播放 | 免费/内购 | 我们提供出版级排版输出 |
| **Newzik** | 数字乐谱管理 | $9.99/月 | 我们聚焦"照片→乐谱"核心功能 |
| **MuseScore** | 免费打谱软件 | 免费 | 我们不需要用户手动输入 |
| **Notion (音乐)** | 专业打谱软件 | $149-499 | 我们全自动，学习成本为零 |

**核心差异化**：市场上没有"拍照上传 → 出版级 LilyPond 乐谱"的端到端在线服务。
