# 乐谱版权与知识产权分析

基于中国《著作权法》及国际公共领域规则，对自动化打谱服务平台涉及的版权问题进行系统分析，明确合规边界与风险应对策略。

---

## 1. 中国音乐著作权基本框架

### 1.1 著作权保护期限

根据《中华人民共和国著作权法》：

| 权利主体 | 保护期限 | 说明 |
|---------|---------|------|
| **自然人** | 作者终生 + 死后 50 年 | 截止于作者死亡后第 50 年的 12 月 31 日 |
| **合作作品** | 最后死亡作者终生 + 50 年 | 截止于最后死亡的作者死亡后第 50 年的 12 月 31 日 |
| **法人作品** | 首次发表后 50 年 | 创作完成后 50 年内未发表的不再保护 |

**关键推论**：
- 贝多芬（1827 卒）、莫扎特（1791 卒）、巴赫（1750 卒）等古典作曲家的作品 → **已进入公共领域**
- 肖邦（1849 卒）、舒曼（1856 卒）→ **已进入公共领域**
- 中国作曲家如聂耳（1935 卒）→ 1935 + 50 = 1985 年后公共领域 → **已进入公共领域**
- 冼星海（1945 卒）→ 1995 年后 → **已进入公共领域**
- 近现代作曲家（1976 年后去世的）→ 需逐一核查

### 1.2 音乐作品的权利结构

一首音乐作品涉及多层权利：

```
音乐作品
    │
    ├── 词曲著作权（Publishing Right）
    │   └── 权利人：词作者 + 曲作者
    │       - 复制权、发行权、出租权、展览权
    │       - 表演权、广播权、信息网络传播权
    │       - 改编权、翻译权、汇编权
    │
    ├── 表演者权
    │   └── 权利人：歌手、乐手
    │       - 表明身份权、保护表演完整权
    │       - 许可录制、复制发行、信息网络传播
    │
    └── 录音制品制作者权
        └── 权利人：唱片公司/录制者
            - 复制、发行、出租、信息网络传播
```

**对本平台的关键影响**：
- 我们处理的是**乐谱**（词曲著作权层），不涉及表演者权和录音制品权
- 只要词曲的著作权保护期已过，即可自由使用
- 对公共领域作品的**新编排**可能产生新的衍生著作权（见 1.3）

### 1.3 衍生作品与编曲的版权地位

**重要区分**：

| 类型 | 版权状态 | 说明 |
|------|---------|------|
| 原创词曲（已过保护期） | 公共领域 | 可自由使用 |
| 对公共领域作品的新编曲 | **可能享有新著作权** | 如果编曲具有独创性 |
| 对公共领域作品的忠实转录 | **不产生新著作权** | 仅是劳务性质，无独创性 |
| 对受保护作品的扒谱/转录 | **侵权风险** | 未经授权复制受保护作品 |

**中国司法实践中的关键认定**：
- 法院曾认定编曲"仅是对原曲进行了乐器配置、声部分工、组合"，属于劳务性质，不具有著作权法意义上的独创性
- 但如果编曲加入了大量原创成分（和声重构、旋律变奏等），可能被认定为改编作品，享有独立著作权
- 我国《著作权法》中没有"编曲权"的专门规定，司法实践中存在较大争议

## 2. 平台业务合规分析

### 2.1 各业务场景的版权风险评估

```
┌──────────────────────────────────────────────────────────────────┐
│ 业务场景                      │ 风险等级 │ 合规路径               │
├──────────────────────────────────────────────────────────────────┤
│ 转录公共领域作品（古典音乐）     │  低 ✅   │ 确认作者已过保护期      │
│ 转录 IMSLP 公共领域乐谱        │  低 ✅   │ IMSLP 已做版权筛查      │
│ 转录用户上传的受保护作品         │  中 ⚠️   │ 用户担责 + 平台免责声明  │
│ 主动抓取并转录受保护作品         │  高 🔴   │ 避免，或获取授权        │
│ 销售对公共领域作品的新排版       │  低 ✅   │ 排版本身不受保护        │
│ 销售包含受保护编曲的乐谱        │  高 🔴   │ 需获得编曲者授权        │
│ 使用网络图片给用户确认          │  中 ⚠️   │ 水印 + 仅确认用途       │
└──────────────────────────────────────────────────────────────────┘
```

### 2.2 安全业务区域（绿灯区）

以下场景法律风险极低，应作为**主营业务优先方向**：

1. **公共领域古典音乐的数字化转录**
   - 贝多芬、莫扎特、巴赫、肖邦等所有保护期已过的作品
   - 来源：IMSLP 公共领域乐谱
   - 我们的 AI 转录 + LilyPond 排版产生的 PDF 是全新的排版，不侵犯任何人的权利

2. **用户自有手稿的数字化**
   - 用户上传自己创作的手写谱 → 我们帮助数字化
   - 用户上传合法持有的乐谱 → 用户自用目的（合理使用范畴内）

3. **已获授权的作品**
   - 通过音著协等集体管理组织获得许可
   - 与独立音乐人直接签约合作

### 2.3 需要谨慎的灰色区域（黄灯区）

1. **用户上传受保护作品要求转录**
   - **法律定性**：用户可能构成复制行为的帮助侵权
   - **应对策略**：
     - 用户协议中明确：用户保证拥有合法权利或已获授权
     - 平台不对用户上传内容的版权状况承担审查义务（避风港原则）
     - 收到投诉后及时下架（通知-删除机制）
     - 不主动将用户定制的受保护作品入库销售

2. **网络抓取乐谱图片（为用户找谱）**
   - **合规做法**：
     - 仅用于向用户确认是否为目标乐谱（临时展示）
     - 必须打水印，防止用户直接使用
     - 不保存/缓存超过合理期限
     - 确认后删除原始抓取图片
   - **最终交付的是自行排版的新乐谱**，不是原始图片

### 2.4 必须避免的红线区域（红灯区）

1. **主动抓取并销售受保护作品的转录版**
   - 即使是"自行排版"，如果原曲仍受保护，未经授权的复制和销售仍构成侵权
   - 乐谱的"内容"（旋律、和声、节奏序列）受保护，不仅仅是"版面"

2. **销售受保护编曲版本**
   - 例如：某流行曲的钢琴改编版，编曲者可能享有改编权
   - 即使原曲已进入公共领域，特定编曲版本可能仍受保护

## 3. IMSLP 与中国版权法的兼容性

### 3.1 IMSLP 版权规则

IMSLP 基于加拿大法律运营，采用**作者终生 + 50 年**的保护期标准。

| 维度 | IMSLP 规则 | 中国法律 | 兼容性 |
|------|-----------|---------|--------|
| 保护期 | 作者终生 + 50 年 | 作者终生 + 50 年 | ✅ 完全一致 |
| 公共领域认定 | 加拿大标准 | 中国标准 | ✅ 标准相同 |
| Urtext 版本 | 出版后 25 年规则 | 无特殊规定 | ⚠️ 需注意 |
| 服务器位置 | 加拿大 | N/A | ✅ 中国用户可合法访问 |

**结论**：IMSLP 主服务器上的公共领域乐谱，在中国同样属于公共领域，可合法使用。

### 3.2 IMSLP 乐谱的使用注意事项

1. **原始版权状态**：IMSLP 对每个文件标注了版权状态，务必检查
2. **扫描件版权**：扫描公共领域乐谱本身不产生新著作权（仅是机械复制）
3. **Urtext 编辑版**：学术考证版可能有编辑者版权，IMSLP 自愿适用 25 年规则
4. **现代编曲**：IMSLP 上也有现代编曲者上传的作品，需检查其许可证（Creative Commons 等）

## 4. 合规策略与实施方案

### 4.1 版权检查流程

```
乐谱进入系统（无论来源）
        │
        ▼
[1] 自动版权预检
        │
        ├── 提取作曲家信息
        │       │
        │       ▼
        │   查询作曲家卒年数据库
        │       │
        │       ├── 卒年 + 50 < 当前年 → ✅ 公共领域，继续流程
        │       │
        │       ├── 卒年 + 50 ≥ 当前年 → ⚠️ 仍受保护
        │       │       │
        │       │       ├── 用户上传 → 要求用户确认授权
        │       │       │
        │       │       └── 主动抓取 → 跳过，不入库
        │       │
        │       └── 无法确定 → 标记为"待人工审核版权"
        │
        ▼
[2] 管理员人工审核
        │
        ├── 确认版权状态
        ├── 确认来源合法性
        ├── 标记版权分类：
        │   - public_domain（公共领域）
        │   - licensed（已获授权）
        │   - user_commissioned（用户委托，不入库销售）
        │   - unknown（待定）
        │
        ▼
[3] 根据版权分类决定处理
        │
        ├── public_domain → 可入库销售 + 淘宝上架
        ├── licensed → 按授权范围销售
        ├── user_commissioned → 仅交付给委托用户，不公开销售
        └── unknown → 暂不上架，继续调查
```

### 4.2 作曲家数据库

系统需维护一个**作曲家版权状态数据库**：

```
Composer（作曲家）
├── id
├── name_zh                    -- 中文名
├── name_en                    -- 英文名/原名
├── name_aliases[]             -- 别名列表
├── birth_year                 -- 出生年
├── death_year                 -- 卒年（null = 在世）
├── nationality                -- 国籍（影响适用法律）
├── copyright_status           -- public_domain / protected / unknown
├── copyright_expires_at       -- 版权到期年份（卒年 + 50）
├── notes                      -- 备注
├── source                     -- 数据来源（IMSLP / 手动录入）
└── verified (boolean)         -- 是否已人工核实
```

**初始数据来源**：IMSLP 的作曲家数据库可批量导入（公开数据）。

### 4.3 用户协议关键条款

平台用户协议（服务条款）应包含以下关键内容：

1. **上传保证条款**
   > 用户保证其上传的乐谱图片为用户合法持有，或已获得著作权人授权进行数字化转录。如因用户上传内容引发的版权纠纷，由用户自行承担法律责任。

2. **平台免责条款（避风港原则）**
   > 本平台为用户提供技术服务，不对用户上传内容进行版权实质审查。平台在收到权利人的有效通知后，将及时删除涉嫌侵权的内容。

3. **定制乐谱使用限制**
   > 通过本平台定制的乐谱仅供用户个人学习、练习和表演使用，不得进行二次商业转售。

4. **公共领域乐谱声明**
   > 本平台销售的公共领域乐谱，其原始音乐作品不受著作权保护。用户购买的是本平台的数字化排版服务和专业排版成果。

5. **通知-删除机制**
   > 如您认为本平台上的乐谱侵犯了您的著作权，请通过 [邮箱] 联系我们，并提供：权利证明文件、侵权内容链接、联系方式。我们将在收到有效通知后 48 小时内处理。

### 4.4 主动抓取的版权安全策略

```
主动抓取决策树：

抓取目标曲目
    │
    ├── 来源 = IMSLP 且标记为公共领域
    │       → ✅ 安全抓取
    │
    ├── 来源 = 其他网站
    │       │
    │       ▼
    │   查询作曲家数据库
    │       │
    │       ├── 确认为公共领域 → ✅ 安全抓取
    │       ├── 仍受保护 → 🔴 跳过
    │       └── 不确定 → ⚠️ 标记待审，不自动入库
    │
    └── 来源 = 用户创作/Creative Commons
            → 按许可证条款处理
```

**主动抓取白名单策略**：
- 优先级 1：IMSLP 公共领域乐谱（最安全）
- 优先级 2：明确标注 Creative Commons 许可的乐谱
- 优先级 3：Musescore 社区分享（需检查个别许可证）
- **不抓取**：任何受版权保护的商业出版乐谱

## 5. 我们的产品 = "排版服务"定位

### 5.1 商业定位的法律意义

将平台定位为**"排版服务"而非"乐谱销售"**具有重要的法律意义：

- **对于公共领域作品**：我们出售的是"专业排版服务的成果"，不是音乐作品本身（音乐作品是免费的）
- **对于用户委托作品**：我们出售的是"AI 转录 + 人工审核的服务费"，类似打字排版服务
- 这种定位有助于：
  - 降低"销售盗版乐谱"的法律风险认知
  - 合理解释为什么公共领域的乐谱仍需收费（排版有成本和价值）
  - 与传统乐谱出版商区分开来

### 5.2 版面权的法律分析

**中国法律中"版面权"相关规定**：

- 《著作权法》第三十七条规定了出版者的"版式设计权"，保护期为 10 年
- 版式设计权保护的是排版格式的外观设计，不保护内容本身
- **对我们的意义**：
  - 我们用 LilyPond 生成的排版是全新的版式设计 → 我们拥有该版式设计的权利
  - 我们不复制任何现有出版商的版面设计
  - 即使转录同一首公共领域作品，不同的排版各自享有独立的版式设计权

## 9. 总结

### 核心原则

1. **公共领域优先**：MVP 阶段只做公共领域作品，这是最安全的业务基础
2. **排版服务定位**：我们卖的是专业排版成果，不是音乐作品本身
3. **用户自担风险**：用户委托转录的受保护作品，版权责任由用户承担
4. **不主动侵权**：主动抓取严格限制在公共领域范围内
5. **及时响应投诉**：建立通知-删除机制，收到投诉 48 小时内处理

### 商业机会

公共领域音乐的库存量极其庞大（IMSLP 有 70 万+ 乐谱文件），足以支撑 MVP 阶段的业务量。随着版权合规体系的完善，再逐步扩展到授权作品领域。
